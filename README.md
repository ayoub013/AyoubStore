# 🛍️ متجري الإلكتروني - AyoubStore

متجر إلكتروني حديث وبسيط لبيع المنتجات عبر واتساب مع الدفع عند الاستلام.

## ✨ المميزات

- 📱 **تصميم متجاوب** - يعمل على جميع الأجهزة (الهاتف، الجهاز اللوحي، الكمبيوتر)
- 🎨 **تصميم عصري** - واجهة مستخدم جميلة وسهلة الاستخدام
- 🇸🇦 **دعم اللغة العربية كاملاً** - واجهة RTL (من اليمين لليسار)
- 💚 **تكامل واتساب** - إرسال الطلبات مباشرة عبر WhatsApp
- 📦 **إدارة سهلة للمنتجات** - يمكن إضافة/تعديل المنتجات بسهولة
- 🚀 **استضافة مجانية** - عبر GitHub Pages

## 🛠️ كيفية التعديل

### إضافة منتج جديد

افتح ملف `index.html` وأضف كود منتج جديد في قسم `products-grid`:

```html
<div class="product-card">
    <img src="رابط_الصورة" alt="وصف الصورة">
    <div class="product-info">
        <div class="product-title">اسم المنتوج</div>
        <div class="product-desc">وصف المنتوج</div>
        <div class="product-bottom">
            <div class="product-price">السعر درهم</div>
            <button class="btn-order" onclick="openOrderModal('اسم المنتوج', 'السعر درهم')">أطلب الآن</button>
        </div>
    </div>
</div>
```

### تغيير رقم الواتساب

عدّل رقم الهاتف في ملف `index.html`:

```javascript
const myPhoneNumber = "رقم_هاتفك_هنا"; // مثال: "212612345678"
```

## 📸 صور للمنتجات
